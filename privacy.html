Morning Intelligence Privacy Policy

Last updated: October 24, 2026

Morning Intelligence is a personal-use application that generates a daily newspaper.

Google Tasks Data

The application requests read-only access to Google Tasks to retrieve task lists, task titles, notes, due dates, and completion status.

Data Usage

Retrieved task data is used to create a personalized daily briefing and printable newspaper on the user's local computer.

Data Storage

OAuth credentials are stored locally. Task information may be included in locally generated newspaper files.

Data Sharing

The application does not sell Google Tasks data or intentionally transmit it to third parties for advertising or analytics.

Access Revocation

Users can revoke access through their Google Account's third-party connections settings.

Contact

For privacy inquiries, contact the project maintainer through the GitHub repository.
